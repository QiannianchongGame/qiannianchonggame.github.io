# 照片素材

这些素材使用 Codex 内置 GPT 图像生成工具制作。游戏使用 WebP 文件，并在构建时将照片嵌入两个 HTML 文件，以支持离线游玩。照片中的日期、人物编号、倒计时以及证物文字由游戏按原始线索叠加，避免生成图片时出现错字或错误数字。

`characters-reference.webp` 是人物形象参考，从左至右、从上至下分别为许嘉、周婷、何蔓、林晚、宋知远、王磊。生日照、证件照、东湖合影和千禧夜合影使用同一参考。千禧夜合影保留六位前排女生、七位后排男生和一位老师；3 号周婷、4 号何蔓挽着胳膊，8 号王磊的 V 手势挡住 9 号马俊的部分脸。

各文件用途、对应游戏内容和提示词概要在 [`src/photo-manifest.json`](../../src/photo-manifest.json)。本次使用的主要提示词如下：

- `birthday.webp`：以原生日照示意图为参考，生成 1998 年中国中学机房里的胶片快照；17 岁男生低头，三位同学围在蛋糕旁，蛋糕上有数字 1 和 7 的蜡烛，背景是 CRT 电脑，右下角留给日期。
- `student-portrait.webp`：以生日照中间的许嘉为人物参考，生成他 1999 年参加信息学竞赛时的证件照；保持相貌、发型和年龄，正面看镜头，穿当年校服。
- `bbs-computer.webp`：1998 年学校机房、米色 CRT 显示器和键盘、旧浏览器主页、荧光灯与胶片颗粒。修改屏幕内容为只有「梧桐树下」和 BBS 的简洁主页，去掉额外日期、网址和学校名称。
- `millennium-group.webp`：保留原合照中的六位女生、后排男生和右侧老师的相貌、性别、服装与站位；增加故事中后排的第 14 人，所有人看镜头，后排适当拉开。周婷穿白羽绒服和红围巾，与穿深绿色外套的何蔓挽手；王磊的 V 手势部分遮挡马俊，手臂和手腕须自然连接。背景是水塔、倒计时牌和大钟，1999 年冬夜闪光灯照片。
- `photo-back.webp`：1999 年冲印照片背面的写实纸张，正面俯视，纸张泛黄、有轻微折痕和两处水渍，不生成文字。
- `ice-group.webp`：1999 年东湖冬季溜冰合照，八人站在后排、五人蹲在前排，许嘉在镜头外拍摄。周婷、何蔓、林晚、宋知远、王磊依照人物参考保持相貌；所有人看镜头，背景有柳树、北岸木牌和危险牌。
- `duty-log.webp`：1999 年教育局值班记录本的俯拍照片；泛黄的空白横线纸、朴素桌面和暖色办公灯光，准确记录由游戏叠加。
- `diary-page.webp`：1998 年学生日记的平视扫描图；米黄色旧纸、蓝色横线和红色页边，日记原文由游戏叠加。
- `key-half.webp`：深蓝物理作业本中夹着撕下的钥匙登记表半行，俯拍，纸张左侧有清晰撕口和表格细线，姓名与签字由游戏叠加。
- `father-notebook.webp`：旧工程师笔记本的俯拍照，米色横线纸、左侧深绿布面装订、木桌和手电光；呼机号码由游戏叠加。
- `evidence-box.webp`：水塔检修口内的夜间手机照片，手电照亮一只旧饼干铁盒，里面有蓝色日记、学校登记表、3.5 英寸软盘和信封；右下角留给准确时间戳。

角色参考图的提示词要求六个独立头像，沿用生日照中四个人的面部特征，并为何蔓、林晚设定不同的脸型与发型。每次合影修订都以此前选定的合照为编辑目标，要求不得改变前排人物的性别和身份。
