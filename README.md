# 千年虫

在旧电脑、校园 BBS 和手机消息之间寻找线索的悬疑解谜游戏。无需安装，也无需注册。

[在线游玩](https://qiannianchonggame.github.io/)

## 游玩

- 标题画面可切换中文、English 和日本語。切换语言会保留当前浏览器的调查进度。
- 英日版保留中文谜题原件，并提供逐行译文、读音或译注；需要输入文字的谜题也接受对应译名及拼音。
- 点击电源启动旧电脑，从手机的消息、邮件和物品中寻找开机线索。
- 聊天底部会显示可发送的回复，即使只有一句，也需要自己点击发送。
- 手机里的照片可以点击放大；电脑中的照片可用查看器按钮缩放，也可以双击进入大图。
- 大图支持放大、缩小、原始大小、适应窗口和拖动查看，按 Esc 关闭。
- 在文件或已打开的图片上右键（触屏长按）可以查看属性；也可以选中文件后点击窗口里的“属性”按钮。
- 手机笔记包含问题、线索、旧事和诗稿。问题页提供本章方向与已确认事实；线索可按章节筛选，旧章节可折叠，并可回到原始资料。线索和物品支持搜索。
- “旧事”随调查自然开放，六段内容可自由阅读，不增加通关条件，也不参与诗稿收集。
- 手机收起后，点击右下角手机按钮可以重新打开。表格支持横向滚动。
- 进度保存在当前浏览器。可以在手机“菜单”中导出、导入存档。

本地文件版和网页版使用各自的浏览器存储。要转移进度，请先在原版本导出存档，再到另一版本导入。

主页的累计访问和在线游玩人数来自独立统计服务。累计访问按访客的连续访问会话去重：刷新、切换语言和同一浏览器打开多个游戏标签页都不重复增加；所有游戏页面退出后再次进入，才新增一次。切到后台或返回游戏标题不算退出。刷新沿用原访问标识，后台页面也会维持访问心跳；未能正常上报的异常断线在 90 秒后按离开处理。只有前台游玩计为在线，约每 30 秒更新。已有累计数字保留，不追溯改算历史访问。

离线版和本地预览不参与统计。统计失败时显示“暂时不可用”，不影响游玩或存档。服务只接收随机标识和游玩状态，不上传昵称、聊天内容或存档。

也可以下载 `千年虫.html`，直接双击离线游玩。推荐使用较新的 Chrome、Edge 或 Safari。

## 构建与检查

修改 `src/` 中的源码，然后运行：

```sh
node tools/validate.js
node tools/simulate.js
node tools/build.js
```

构建同时生成内容一致的 `index.html`（网页入口）和 `千年虫.html`（离线版）。写实照片会嵌入 HTML，离线版无需额外下载图片。素材和生成说明位于 `assets/photos/`。正式版不开放调试接口。

统计界面和连接配置分别位于 `src/stats.js`、`src/stats-config.json`。[独立统计服务](https://qiannianchong-stats.chenhao2003.chatgpt.site)的源码在 `services/qiannianchong-stats/`，由 Sites 的单独仓库管理；主仓库忽略这个目录，避免误提交嵌套仓库。服务使用持久化数据库保存累计数，并对临时心跳记录自动清理。服务检验运行 `node scripts/stats-test.mjs`；在本机已有服务源码时，可从游戏目录运行 `node tools/stats-ui-check.js --webkit` 进行浏览器集成检查。

浏览器交互检查需要 Node.js 和 Playwright，以及相应浏览器；Playwright 应位于 Node.js 的模块查找路径中。Chromium 可通过 `UI_CHECK_BROWSER` 指定可执行文件。

```sh
node tools/ui-check.js
node tools/ui-check.js --webkit
node tools/desktop-touch-check.js --webkit
node tools/i18n-check.js en
node tools/i18n-check.js ja
node tools/i18n-evidence-check.js
node tools/i18n-runtime-check.js --webkit
```

检查覆盖图片显示和缩放、手机横竖屏、手动回复、连续点击、存档恢复、作答、阅读位置、未读状态和窗口操作。测试使用独立浏览器环境，不会读取或修改玩家存档。

`desktop-touch-check.js` 逐项验证手机端模拟电脑的桌面入口、回收站还原、文件菜单、任务栏、鸽讯、播放器、解压和后台筛选，同时覆盖浏览器不补发点击的触屏情况。

翻译检查覆盖九份内容文件与每种语言的 410 条界面文字，并在正式构建中核对全部译文字段、44 个谜题、中文取字材料、证据数字、照片译注、文件路径、语言切换及存档保留。英日版的手机论坛搜索、后台登录和旧事阅读也参与浏览器检查。

## 发布

组织主页仓库为 `QiannianchongGame/qiannianchonggame.github.io`，GitHub Pages 从 `main` 分支根目录发布。

更新源码并完成检查后，运行构建，提交生成的两个 HTML 文件和相关源码，再推送到 `main`。GitHub Pages 会自动发布。`.nojekyll` 用于直接发布静态文件。

`docs/` 与源码包含完整剧情及解谜信息，请在通关后阅读。
